# 🌴 Tamr – Premium Dates E-commerce Website

Tamr is a modern e-commerce website for a premium dates brand based in Malappuram, Kerala.
It focuses on delivering high-quality imported dates such as Ajwa and Medjool with a seamless and elegant online shopping experience.

The project highlights how AI-assisted tools can be used to rapidly design and build real-world digital products.

---

## 🚀 Features

* Premium product showcase for luxury date varieties (Ajwa, Medjool, etc.)
* Clean, modern, and responsive UI design
* Dedicated product pages with detailed descriptions and pricing
* Kerala-wide ordering flow
* Festival offers (Ramadan & Eid special collections)
* Blog section for recipes and health benefits of dates
* Customer testimonials for trust and credibility
* Smooth navigation and user-friendly experience
* SEO-friendly structure

---
